Urban Air Quality Assistant - Backend Setup

This frontend can connect to your local FastAPI backend at http://localhost:8000 or run fully standalone with its built-in RAG engine.

1. Install dependencies:
pip install fastapi uvicorn python-dotenv requests numpy pydantic
2. Add Gemini API key to .env (optional):
GEMINI_API_KEY=AIzaSy...your_gemini_key
3. Start the application:
python main.py
